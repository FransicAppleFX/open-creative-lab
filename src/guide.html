MAINTENANCE GUIDE

让模板，持续生长。

四套独立用途的页面，共享一个静态站点。无构建依赖，无数据库，内容与本机项目无关。

四套模板的边界

Fieldnotes：原创产品发布模板；工作流为本地交互示例，不调用 AI。

Pulse：读取公开 GitHub 仓库指标。发布时快照和手动刷新均显示时间；没有历史增长数据，不代表 GitHub Trending。

Common Ground：个人任务保存在当前浏览器，可导出导入；不连接 GitHub Issue，不是多人协作服务。

Open Atlas：官方入口目录，支持浏览器内收藏与自定义链接；不是公开投稿平台。

GitHub 维护流程

将源码放进你指定的 GitHub 仓库，用分支、Pull Request 与检查管理修改。合并后，通过 Codex 的 Sites 工具同步同一份代码、保存版本并部署。GitHub 推送和 Sites 发布是两个步骤。

当前模板附带 GitHub Actions 检查配置；尚未绑定 GitHub 仓库，也没有配置 GitHub 自动部署。Sites 的短期发布凭证不能作为长期 GitHub Secret 使用。

从源文件到发布

src/ 修改页面与交互；src/data/ 维护精选资源和仓库快照。执行 npm run check、npm run build 后，使用 Sites 保存并部署。

维护热度快照时，执行 npm run refresh。这只访问固定名单中的 GitHub 公共 API，不发送你的账号凭证。

社区灵感与来源

模板为原创实现，没有复制下列项目的源码或品牌。社区案例帮助确定用途与信息结构：

  • shadcn-admin：管理后台与数据界面
  • AstroWind：产品与内容宣传页面
  • ShadcnStore：宣传页与看板组合
  • OpenAI Sites：托管和发布说明

数据与隐私

本站不提供账号注册、不收集表单、不保存访问者的任务或收藏到服务端。手动刷新看板会从浏览器请求 api.github.com，受 GitHub 公共 API 的限流和网络条件影响。清除浏览器数据会移除本地任务和收藏，重要内容请先导出。
